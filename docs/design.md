# Gaijincall 設計討論

更新日期：2026-10-09。狀態：修訂範圍已整理，待用戶確認完整第一版；尚未開始實作。

## 最新已確認第一版

- 本機即時語音對話，先不使用雲端 AI API。
- 用戶使用自己正常 Discord 帳號，自己登入及進入 server 嘅語音房。
- Discord 只用作語音對話，本機助手收聽對方聲音並透過音訊輸入播出 AI 回覆。
- 語言：廣東話、普通話、日文及英文。
- 用戶手動開啟 AI 對話模式後自動對答，快捷鍵可以暫停，讓用戶自己講嘢。
- 第一版先一對一驗收，之後再擴展多人語音房。
- 自動跟對方語言回覆，亦可手動鎖定其中一種。
- 本機繁中網頁控制台負責啟用／停止、音訊裝置、語言及對話狀態。
- 本機會話不設固定時間上限；對方可以打斷 AI 未播完嘅回覆。
- 錄音、保存逐字稿及分析報告後加；第一版先驗證即時對話。
- 第一版 AI 唔會主動講明自己係 AI（用戶決定，2026-10-09）。日後加入錄音時，沿用下面嘅錄音政策。
- 詳細範圍及驗收：[milestone-1.md](milestone-1.md)。

## 已查證環境及候選

- 本機 GPU：NVIDIA GeForce RTX 5070 Ti，約 16 GB VRAM；系統 RAM 約 32 GB。
- Windows 11 Pro，build 26200；符合 Microsoft application loopback 文件嘅最低 build 20348。
- Discord desktop 正在運行；本機有 MOTIV Mix Virtual Input／Output、Shure MV7+ 實體咪及 INZONE Buds。現有虛擬音訊可先評估，未驗證混音及 Discord 輸入路由。
- Qwen3-ASR、Qwen3 文字模型及 OmniVoice 官方文件分別提供廣東話、普通話、日文與英文支援。
- 既有 OmniVoice／local-voice-studio 有本機環境及模型資源，但不代表本次即時對話、延遲或聲音路由已通過驗收。
- OmniVoice 現有生成路徑先產生完整語句；串流 TTS 候選另外需要運行與品質測試。
- 尚未安裝音訊 driver、改動 Discord 設定、捕捉真人聲音或運行模型。

## 尚待技術驗證

- 指定 Discord process 收音、虛擬咪播音及裝置選擇。
- 四種語言嘅辨識／回覆／發聲品質。
- 端到端回覆延遲、打斷與 GPU／RAM 資源需求。
- 防止 AI 自我接話及音訊回授。
- 快捷鍵暫停、用戶自己講嘢及恢復 AI 嘅行為。
- Discord echo cancellation／降噪等設定對合成聲音嘅影響。

## 保留嘅後續方向

原始方向包括日文實際電話打出／接聽、錄音及分析；目前先完成 Discord 本機語音。

之前曾評估 GPT-Live 1 同 Discord bot 接駁。新第一版改用正常 Discord 客戶端音訊路由，暫不使用呢兩條路線。相關費用記錄保留於 [costs.md](costs.md)，供日後評估。

先前預算：電話加 AI API 每月最多 ¥1,000，一次性開通費最多 ¥2,000。第一版不產生雲端 AI API 費用。

日後加入錄音／報告時，沿用已確認政策：表明 AI 身份及問錄音同意；拒絕只保留結果／待辦；資料永久存本機，由用戶手動刪除。餐廳任務嘅授權條件及 30 秒批准流程屬後續電話／任務功能。
